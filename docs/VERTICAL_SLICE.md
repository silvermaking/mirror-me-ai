# Mirror Me AI — 첫 30초 수직 슬라이스 기획

## 1. 이 문서의 목적

이 수직 슬라이스는 완성 게임의 축소판이 아니다. 첫 30초 안에 현재 기획의 세 가지 약속이 실제 플레이로 성립하는지만 검증한다.

1. 첫 유효 문 선택 뒤 10초 안에 핵심 훅이 완결되는가?
2. 플레이어가 AI의 예측과 그 원인을 화면만 보고 이해하는가?
3. 게임 오버 뒤 다음 행동을 떠올리고 즉시 다시 시험하는가?

세 질문 중 하나라도 실패하면 새로운 학습 축이나 콘텐츠를 추가하지 않는다. 실패한 장면의 문 배치, 기억 결합, 잠금, 결과 피드백 또는 사망 카드만 다시 고친다.

## 2. 검증 범위

### 포함

- 하나의 원형 전장과 하나의 AI 보스
- 이동과 대시
- 현재 플레이어 위치에서 등거리인 좌우 탈출문
- 최근 선택 세 칸을 보여 주는 기억 링
- `LOCK`, `OUTSMART`, `READ`, `READ CONFIRMED`, `BREAK FAILED`
- 보스 미러 보호막 두 칸과 플레이어 신호 보호막 세 칸
- 첫 라운드 완료, 게임 오버, 1.25초 뒤 즉시 재도전
- 죽은 전장에서 보여 주는 사망 원인과 다음 행동 하나

### 제외

- 대시·거리·공격 타이밍의 학습
- `COUNTER-READ`
- 회전하는 문 축과 후반 라운드 난이도
- `OVERCLOCK`
- 점수 밸런스와 결과 공유 기능의 평가
- 여러 보스, 장비, 성장, 스토리
- 게임 코드와 기술 구조

이 단계에서는 세 가지 상태 분기의 명료성만 본다.

## 3. 공통 도입: 0~5.4초

모든 검증 루트는 같은 입력으로 시작한다.

> **오른쪽 → 왼쪽 → 오른쪽**

AI가 다수인 오른쪽을 예측하며, 첫 `LOCK`에 대한 플레이어의 답에서 세 루트가 갈라진다.

| 시간 | 플레이 장면 | 상태 |
| --- | --- | --- |
| 시작 전 | 플레이어가 등거리의 좌우 시작문 사이에 선다. | 어느 문을 통과하든 게임 시작과 첫 표본이 된다. |
| 0.0초 | 오른쪽 시작문을 통과한다. | 기억 `오른쪽` |
| 0.6~2.0초 | 현재 위치 기준 등거리 문 중 왼쪽을 통과한다. | 기억 `오른쪽 · 왼쪽` |
| 2.0~3.4초 | 새 등거리 문 중 오른쪽을 통과한다. | 기억 `오른쪽 · 왼쪽 · 오른쪽` |
| 3.4~4.2초 | 오른쪽 기억 조각 두 개가 결합하고 왼쪽 조각은 어두워진다. | 확신 예측 `오른쪽` |
| 4.2~5.1초 | 결합한 조각이 오른쪽 미래 잔상과 자홍 공격 레일로 변한다. | 보스의 눈은 실제 플레이어가 아니라 잔상을 본다. |
| 5.1~5.4초 | 레일과 시선이 `철컥` 소리와 함께 굳는다. | `LOCK: 오른쪽` |

5.4초부터 플레이어는 다음 중 하나를 실제로 선택한다.

- 반대인 왼쪽 문으로 즉시 배신한다.
- 예상한 오른쪽 문을 유지하되 정밀 회피한다.
- 예상한 오른쪽 문으로 가서 공격에 맞는다.

## 4. 루트 A — 즉시 배신하는 안전 루트

이 루트는 보스의 확신이 생기자마자 배신한다. 한 번의 반사 피해는 작지만 실행 위험이 낮다.

| 시간 | 플레이 장면 | 결과 |
| --- | --- | --- |
| 5.4~7.5초 | 반대인 왼쪽 문을 먼저 통과하고 공격 종료까지 회피한다. | 예측은 오른쪽에 고정된 채 빗나간다. |
| 7.5~8.3초 | 백금색 균열이 공격 레일을 역류한다. | `OUTSMART`, 보스 보호막 `2→1`, 기억은 `왼쪽` 한 칸만 남는다. |
| 8.3~10.7초 | 기억 링의 빈 두 칸을 왼쪽 선택 두 번으로 채운다. | 기억 `왼쪽 · 왼쪽 · 왼쪽` |
| 10.7~12.5초 | AI가 왼쪽 문을 예측하고 잠근다. | 확신 `LOCK: 왼쪽` |
| 12.5~14.2초 | 오른쪽 문으로 배신하고 공격 종료까지 회피한다. | 두 번째 오판 |
| 14.2~15.0초 | 두 번째 반사가 보호막 마지막 칸을 깬다. | `OUTSMART`, 보스 보호막 `1→0`, 1라운드 완료 |
| 15.4~22.1초 | 실제 오른쪽 기억 한 칸을 유지한 채 오른쪽 표본 두 개를 더 심고 왼쪽으로 배신한다. | 2라운드 보호막 `2→1` |
| 22.1~28.8초 | 실제 왼쪽 기억 한 칸에서 두 표본을 채우고 오른쪽으로 배신한다. | 2라운드 보호막 `1→0` |
| 28.8~30초 | 실제 오른쪽 기억 한 칸을 유지한 채 3라운드를 시작한다. | 다음 탐색 시작 |

### 30초 예상 상태

- 완료 라운드: 2
- `OUTSMART`: 4회
- 플레이어 보호막: 3
- 예상 점수: 6,300점

### 반드시 보여야 하는 인과

- 첫 `OUTSMART`는 반대 문 진입 순간이 아니라 공격 종료까지 무피격이 확인된 뒤 한 번만 발생한다.
- 첫 반사 뒤 `오른쪽 · 왼쪽 · 오른쪽` 기억은 깨지고 실제 왼쪽 조각 하나만 남는다.
- 다음 탐색은 세 번이 아니라 빈 칸만 채우는 두 번이다.
- 첫 속임은 고착이 아니므로 보스 보호막을 한 칸만 파괴한다.

## 5. 루트 B — 한 번 더 믿게 만드는 고착 루트

이 루트는 첫 예측을 일부러 확인시켜 더 위험하고 큰 반사를 노린다.

| 시간 | 플레이 장면 | 결과 |
| --- | --- | --- |
| 5.4~7.5초 | 예상한 오른쪽 문을 먼저 통과하되 정밀하게 공격을 피한다. | 예측과 실제 방향은 같지만 피격은 없다. |
| 7.5~8.3초 | 균열이나 보호막 손상 없이 기억 링이 단단히 잠긴다. | `READ CONFIRMED`, 양쪽 보호막과 기억 유지 |
| 8.3~9.3초 | 탐색 없이 같은 오른쪽을 노리는 고착 판독이 더 짧게 잠긴다. | `고착 LOCK: 오른쪽` |
| 9.3~11.1초 | 이번에는 왼쪽 문으로 배신한다. | 고착 예측 오판 |
| 11.1~11.9초 | 강한 반사가 보스 보호막 두 칸을 한 번에 깬다. | `OUTSMART`, 보스 보호막 `2→0`, 1라운드 완료 |
| 12.3~20.0초 | 실제 왼쪽 기억 한 칸에서 새 확신을 만들고, 예상한 문을 다시 정밀 회피한다. | 2라운드 `READ CONFIRMED` |
| 20.0~23.4초 | 같은 문 고착 판독을 반대 문으로 깨뜨린다. | 2라운드 완료 |
| 23.8~30초 | 실제 오른쪽 기억 한 칸으로 3라운드를 시작한다. | 다음 고착 유도 직전 |

### 30초 예상 상태

- 완료 라운드: 2
- `OUTSMART`: 2회
- 플레이어 보호막: 3
- 예상 점수: 7,200점

### 반드시 보여야 하는 인과

- `READ CONFIRMED`에는 피해, 반사, 점수, 기억 초기화가 없다.
- `READ CONFIRMED` 뒤에는 새 탐색이 나오지 않는다.
- 같은 문을 노리는 고착 판독이 즉시 이어진다.
- 고착 판독은 잠금 시간이 짧지만 잠긴 뒤 반대 문을 추적하지 않는다.
- 고착 반사는 `OUTSMART` 한 번으로만 집계되며 보스 보호막 두 칸을 파괴한다.

## 6. 루트 C — 읽히고 죽은 뒤 바로 반박하는 루트

이 루트는 같은 예측 문에서 세 번 피격되어 게임 오버를 만들고, 재도전 후 결과 카드가 제시한 행동을 즉시 시험한다.

| 시간 | 플레이 장면 | 결과 |
| --- | --- | --- |
| 5.4~7.5초 | 예상한 오른쪽 문으로 가서 피격된다. | 첫 `READ`, 플레이어 보호막 `3→2`, 오른쪽 고착 |
| 8.3~10.9초 | 탐색 없이 같은 오른쪽 고착 판독이 이어지고 다시 피격된다. | 두 번째 `READ`, `2→1` |
| 11.7~14.3초 | 같은 판독에서 세 번째로 피격된다. | 세 번째 `READ`, `1→0`, 게임 오버 |
| 14.3~15.55초 | 죽은 전장에서 기억, 예측 문, 실제 충돌을 순서대로 보여 준다. | `다음에는 LOCK 뒤 예측의 반대 문` |
| 15.55초 | `다시 속이기`를 누른다. 죽음 흔적과 기억 링이 깨진다. | 기억 0칸, 플레이어 3칸, 보스 2칸, 1라운드로 초기화 |
| 15.6~21.0초 | 다시 `오른쪽 · 왼쪽 · 오른쪽`을 심어 오른쪽을 잠근다. | 이전 플레이와 같은 시험 재현 |
| 21.0~23.1초 | 이번에는 왼쪽 문으로 배신하고 공격 종료까지 회피한다. | 예측 오판, 반사 판정 시작 |
| 23.1~23.9초 | 역류 균열이 첫 보호막을 깬다. | `OUTSMART`, 방금 본 결론을 반박 |
| 23.9~29.8초 | 왼쪽 기억에서 새 확신을 만들고 오른쪽으로 두 번째 배신을 실행한다. | 두 번째 공격 종료, 반사 판정 시작 |
| 29.8~30.6초 | 두 번째 역류 균열이 마지막 보호막을 깬다. | 30초에는 결과 연출 중, 약 30.6초에 재도전한 1라운드 완료 |

### 30초 예상 상태

- 첫 플레이: 약 14.3초에 게임 오버
- 약 1.25초 뒤 재도전 가능
- 재도전 약 8.3초 뒤 첫 반박 성공
- 30초에는 두 번째 반사 결과가 진행 중이며 약 30.6초에 재도전한 1라운드 완료

### 반드시 보여야 하는 인과

- `READ` 사이에는 새 탐색이 들어가지 않고 같은 고착 판독이 이어진다.
- 사망 카드에는 기억 슬롯 `오른쪽 · 왼쪽 · 오른쪽`의 다수 방향, AI 예측, 치명타의 실제 선택이 모두 오른쪽으로 일치해야 한다.
- 기록보다 `다음에는 LOCK 뒤 예측의 반대 문`과 `다시 속이기`가 먼저 보인다.
- 재시작 시 이전 플레이의 기억, 보호막 손상, 라운드 진행이 남지 않는다.
- 재도전 첫 판독에서 왼쪽을 고르면 카드가 제시한 행동이 실제 성공으로 확인된다.

## 7. 여섯 개의 시각 키프레임

여섯 장면은 하나의 시각 문법을 공유한다. 비교용 화면에서는 나란히 볼 수 있지만, 실제 고착 루트의 시간 순서는 `READ CONFIRMED → 고착 OUTSMART`여야 한다.

### 1) BAIT

현재 청록 궤적 하나만 전장에 남고, 지나간 선택은 즉시 작은 기억 조각으로 접혀 링에 들어간다. 세 개의 긴 과거 궤적을 동시에 남기지 않는다.

### 2) LEARN / LOCK

두 다수 조각이 물리적으로 맞물리고 소수 조각은 어두워진다. 결합한 모양이 그대로 미래 잔상과 자홍 공격 레일로 늘어난다. 조각, 잔상, 레일을 한 프레임에 갑자기 동시에 만들지 않고 약 0.2초 간격으로 변환한다.

### 3) OUTSMART

자홍 레일은 예상 문에 남고, 실제 백색 궤적은 반대 문으로 갈라진다. 공격이 빈 잔상을 친 뒤 백금색 균열이 보스 보호막까지 역류한다.

### 4) READ CONFIRMED

예측선과 실제선이 같은 문에서 포개지지만 충돌, 금빛 균열, 보호막 손상은 없다. 기억 조각만 더 짙은 자홍 클램프로 굳어 고착을 예고한다.

### 5) GAME OVER

죽은 전장을 그대로 멈춘다. 기억 조각, 예측 문, 실제 충돌을 순서대로 밝힌 뒤 반대 문 하나만 청록색으로 맥동시킨다. 리플레이, 긴 문장, 네 기록, 버튼을 동시에 띄우지 않는다.

### 6) CHANGE

기억 링과 죽음 흔적이 깨져 초기화된 같은 전장에서 이전과 같은 미끼를 심는다. `LOCK` 뒤 게임 오버에서 맥동했던 반대 문으로 실제 백색 경로를 바꿔 오판을 증명한다.

### 공통 시각 언어

- 현재 플레이어: 청록 실체
- 과거: 청록 점선과 빈 화살촉
- 기억: 청록 유리 조각
- 예측: 자홍 실선, 채운 화살촉, 미래 잔상
- 잠금 뒤 실제 선택: 가는 백색 실선
- 오판 반사: 백금색 역류 균열

## 8. 상태 감사

세 루트를 오른쪽 중심과 왼쪽 중심으로 각각 재현해 총 여섯 번 검사한다.

### 전체 PASS 조건

- 여섯 번 모두 기억 조각, 예측 문, 결과 문구, 양쪽 보호막, 다음 상태가 문서와 100% 일치한다.
- `LOCK` 이후 시선, 미래 잔상, 공격 레일이 플레이어를 다시 추적하지 않는다.
- 한 판독에서 결과가 중복 집계되지 않는다.
- `OUTSMART` 뒤 실제 선택 한 칸만 남고 빈 두 칸까지만 탐색한다.
- `READ`와 `READ CONFIRMED` 뒤에는 탐색이 삽입되지 않는다.
- 사망 카드의 원인과 실제 충돌 궤적이 일치한다.
- 재시도 뒤 이전 플레이의 기억과 진행이 남지 않는다.

하나라도 다르면 수직 슬라이스는 FAIL이다.

## 9. 초행 플레이테스트

최소 다섯 명에게 규칙을 설명하지 않고 첫 플레이를 맡긴다. 결과 문구를 읽었는지가 아니라 장면의 인과를 이해하고 다음 행동으로 옮겼는지를 관찰한다.

검증은 서로 다른 분기를 한 번의 자유 플레이에 억지로 요구하지 않고 두 단계로 나눈다.

1. **자유 첫 시도:** 시작부터 첫 판독, 첫 게임 오버, 첫 재도전까지 개입하지 않는다. 첫 10초의 훅과 실제 재도전 행동을 본다.
2. **분기 재현:** 자유 첫 시도가 끝난 뒤 루트 B와 루트 C를 각각 새 플레이의 1라운드 첫 주기로 초기화해 독립적으로 경험하게 한다. 입력 방법만 알려 주고 결과의 뜻은 설명하지 않은 채 `READ CONFIRMED`와 사망 카드의 전달력을 따로 본다.

### 합격선

두 단계 모두에서 다섯 명 중 네 명 이상이 다음 조건을 만족해야 한다.

### 자유 첫 시도 합격 조건

1. 첫 유효 문 통과 뒤 10초 안에 첫 판독 결과를 경험한다.
2. 첫 결과 직후 AI가 어느 문을 예측했으며 왜 그 문을 골랐는지 직전 세 선택으로 설명한다.
3. 결과를 `AI가 맞힘`, `내가 속임`, `문 선택은 속였지만 회피 실패` 중 정확한 하나로 구분한다.
4. 첫 게임 오버 뒤 별도 설명 없이 3초 안에 `다시 속이기`를 누르고, 다음 판에서 사망 카드가 제안한 행동을 실제로 시도한다.

### 분기 재현 합격 조건

1. 루트 B의 `READ CONFIRMED`를 본 뒤 “지금 피해는 없지만 AI의 믿음이 강해져 다음 반사는 더 크고 더 위험하다”는 의미를 설명한다.
2. 루트 C의 게임 오버 뒤 3초 안에 `다시 속이기`를 누르고, 재도전 첫 `LOCK`에서 안내된 반대 문을 실제로 선택한다.

### 관찰 질문

- “보스는 다음에 어느 문을 노렸나요?”
- “왜 그 문이라고 생각했나요?”
- “공격선은 잠긴 뒤 당신을 따라왔나요?”
- “방금 결과는 읽힘, 속임, 실행 실패 중 무엇인가요?”
- “다음 판에서는 한 가지만 무엇을 바꾸겠나요?”

## 10. 실패했을 때의 디렉팅 원칙

- 기억의 원인을 이해하지 못하면 궤적이 조각으로 접히는 장면을 고친다.
- 예측 문을 알아보지 못하면 조각이 잔상과 레일로 변하는 연결을 고친다.
- `LOCK`을 불공정한 추적으로 느끼면 잠금 정적과 고정된 시선·레일을 더 분명히 한다.
- `READ CONFIRMED`를 승리나 피격으로 오해하면 충돌, 균열, 보호막 반응을 제거하고 고착 클램프만 남긴다.
- 재도전이 늦으면 기록을 더 줄이고 원인, 반대 문, `다시 속이기`의 순서를 앞당긴다.
- 반대 문 선택이 너무 단순해 지루하다면 먼저 잠금 시간과 고착 회피 리듬을 조정한다. 새 학습 축은 추가하지 않는다.

상태 감사 여섯 번이 모두 일치하고 초행 다섯 명 중 네 명 이상이 합격하기 전에는 게임 구현 범위를 넓히지 않는다.
