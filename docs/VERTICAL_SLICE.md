# Mirror Me AI — 2.5D 첫 30초 수직 슬라이스 기획

## 1. 이 문서의 목적

이 수직 슬라이스는 완성 게임의 축소판이 아니다. 직접 조작하는 2.5D 액션 보스전으로 방향을 바꾼 뒤, 첫 30초 안에 세 가지 약속이 실제 플레이 장면으로 성립하는지만 검증한다.

1. 첫 전투 입력 뒤 10초 안에 직접 이동·대시·공격과 첫 AI 판독이 한 번 완결되는가?
2. 플레이어가 AI가 자신의 대시를 학습했다는 것을 화면만 보고 이해하는가?
3. 게임 오버 뒤 반대 행동을 떠올리고 즉시 다시 싸우는가?

세 질문 중 하나라도 실패하면 새 무기, 보스 패턴, 학습 축을 추가하지 않는다. 실패한 공격 예고, 기억 결합, `LOCK`, 코어 노출, 직접 타격 또는 사망 장면만 다시 고친다.

## 2. 검증 범위

### 포함

- 고정 쿼터뷰의 원형 2.5D 전장
- 자유 평면 이동, 근접 공격, 이동 방향 대시
- 플레이어보다 약 다섯 배 큰 단일 AI 보스
- 탐색 베기에 대한 첫 횡대시 착지 측면 하나의 학습
- 최근 유효 대시 세 칸과 2/3 다수 예측
- 미래 플레이어 잔상, 요격 구역, `LOCK`
- `OUTSMART`, `READ`
- 닫힌 장갑, 약 2초의 코어 노출, 여섯 칸의 코어 체력
- 플레이어 보호막 세 칸
- 보스 직접 처치, 게임 오버, 1.25초 뒤 재도전

### 제외

- 좌우 탈출문과 선택 대기
- 자동 반사 피해와 미러 보호막
- `READ CONFIRMED`, 고착, `BREAK FAILED`, `DODGE FAILED`
- 카메라 회전, 점프, 높이 회피, 수직 조준
- 여러 무기, 원거리 조준, 스킬, 성장
- 거리·공격·자유 이동 좌표의 추가 학습
- 여러 보스와 여러 공격 패턴
- 점수 밸런스와 후반 라운드 평가
- 게임 코드와 기술 구조

## 3. 화면에서 절대 바뀌지 않는 약속

- 카메라 축과 조작 방향은 전투 내내 고정된다.
- 플레이어, 보스, 바닥 그림자, 현재 공격의 전체 위험 범위가 한 화면에 보인다.
- 캐릭터가 입체적으로 뛰어오르는 연출이 있어도 판정은 바닥 도형과 그림자에만 있다.
- 보스 몸체, 전경 장식, 파편, 섬광이 플레이어나 `LOCK` 레일을 가리지 않는다.
- `LOCK` 뒤 보스 눈, 무기, 미래 잔상, 공격 레일은 실제 플레이어를 다시 추적하지 않는다.
- `OUTSMART`만으로 보스 체력이 줄지 않는다. 열린 코어에 실제 검격이 닿을 때만 줄어든다.

## 4. 공통 도입: 0~7.7초

세 검증 루트는 같은 시작을 사용한다.

> **오른쪽 대시 → 오른쪽 대시 → 오른쪽 대시**

| 시간 | 실제 플레이 장면 | 상태 |
| --- | --- | --- |
| 0.0~0.7초 | 플레이어가 닫힌 보스 장갑을 직접 벨 수 있다. 청록 불꽃은 튀지만 체력은 줄지 않는다. | 공격 입력과 장갑 규칙 확인 |
| 0.7~2.0초 | 첫 탐색 베기의 중심선 오른쪽으로 대시한다. | 기억 `오른쪽` |
| 2.0~3.3초 | 두 번째 탐색 베기도 오른쪽으로 대시한다. | 기억 `오른쪽 · 오른쪽` |
| 3.3~4.6초 | 세 번째 탐색 베기도 오른쪽으로 대시한다. | 기억 `오른쪽 · 오른쪽 · 오른쪽` |
| 4.6~5.3초 | 세 기억 조각이 자홍색으로 결합하고 오른쪽 예상 착지 구역에 미래 잔상이 생긴다. | 예측 `오른쪽` |
| 5.3~5.9초 | 보스 눈, 무기, 공격 레일이 미래 잔상에 고정된다. | `LOCK: 오른쪽` |
| 5.9~7.3초 | 판독 공격이 고정된 오른쪽 착지 구역 전체를 향한다. | 실제 대시에서 루트 분기 |
| 7.3~7.7초 | 반대로 피했으면 보스가 과회전하며 코어가 열린다. 읽혔다면 7.3초에 피격되고 짧은 재잠금이 시작된다. | `OUTSMART` 또는 `READ` |

첫 `LOCK` 뒤 다음 세 경로를 각각 검증한다.

- 반대인 왼쪽으로 대시하고 코어에서 세 번 공격한다.
- 반대인 왼쪽으로 대시하고 코어에서 두 번만 공격한다.
- 예상한 오른쪽으로 계속 대시해 세 번 읽힌 뒤 재도전한다.

| --- | --- | --- |

| 7.3~7.7초 | 보스가 빈 오른쪽 잔상을 내려치고 왼쪽 후면 코어가 열린다. | `OUTSMART`, 보스 체력 변화 없음 |

- 첫 속임 뒤 기존 기억은 깨지고 실제 왼쪽 대시 한 칸만 남는다.
- 라운드가 바뀌어도 마지막 실제 오른쪽 대시 한 칸은 유지된다.

- 재도전에서 `OUTSMART`만으로 체력이 줄지 않고 후속 검격 세 번에서만 줄어든다.

## 8. 여섯 개의 시각 키프레임

### 1) ENGAGE

플레이어가 거대한 보스 장갑을 직접 벤다. 닫힌 장갑에는 청록 불꽃만 튀고 상단 보스 체력은 그대로다. 동시에 보스의 주황 탐색 베기가 바닥에 넓게 예고된다.

### 2) REMEMBER

청록 대시 흔적 하나가 짧게 남았다가 보스 센서의 물리적 방향 조각으로 접힌다. 센서에는 정확히 세 칸만 있고, 긴 과거 궤적 여러 개를 전장에 남기지 않는다.

### 3) LOCK

다수 기억 조각이 자홍색으로 결합해 미래 플레이어 잔상, 예상 착지 구역, 고정 공격 레일로 변한다. 보스 눈은 현재 플레이어가 아니라 잔상을 본다.

### 4) BREAK

자홍 예측 경로와 청록 실제 대시가 V자로 갈라진다. 보스의 시선과 무기는 자홍 잔상에 고정되어 실제 플레이어를 따라오지 않는다.

### 5) EXPOSE

보스가 빈 착지 구역을 내려치며 과회전한다. 백금·금색 균열이 빗나간 팔에서 흉부까지 역류하고 반대 측면 코어 셔터가 열린다. 아직 체력은 줄지 않는다.

### 6) STRIKE

같은 고정 카메라에서 플레이어 무기와 코어가 직접 접촉한다. 짧은 청록 초승달 검격과 타격 정지가 발생하며 이 장면에서만 보스 체력이 한 칸 감소한다.

### 공통 시각 언어

- 일반 위험: 주황 바닥 도형
- 실제 플레이어와 현재 대시: 청록 실체와 직선 잔상
- 과거 기억: 청록 점선과 보스 장갑에 박힌 조각
- AI 미래: 자홍 실선, 와이어 잔상, 착지 표적
- 오판과 열린 코어: 백금·금색 균열
- 직접 공격: 짧은 청록 초승달과 무기 접촉 섬광

## 9. 상태 감사

루트 A, B, C를 오른쪽 다수와 왼쪽 다수로 각각 재현해 총 여섯 번 검사한다.

### 전체 PASS 조건

- 여섯 번 모두 기억 조각, 예측 측면과 착지 구역, 실제 대시, 결과 문구, 플레이어 보호막, 보스 코어 체력, 다음 상태가 문서와 일치한다.
- 공격 입력 없이 `OUTSMART`만 반복하면 보스 체력이 줄지 않는다.
- 닫힌 장갑을 아무리 공격해도 보스 체력이 줄지 않는다.
- 열린 코어에 검격이 닿은 횟수와 줄어든 체력 칸이 정확히 같다.
- `LOCK` 뒤 시선, 미래 잔상, 무기, 바닥 레일이 플레이어를 다시 추적하지 않는다.
- `OUTSMART` 뒤 실제 반대 대시 한 칸만 기억에 남는다.
- `READ` 뒤 기억을 유지하고 탐색 없이 같은 예측이 재잠긴다.
- 예측 구역에 갔지만 무피격이면 코어와 기억을 유지한 채 같은 예측이 재잠긴다.
- 반대 측면으로 향했지만 잠금 전에 움직여 피격되면 코어는 열리지 않고 실제 반대 대시 한 칸에서 탐색을 재개한다.
- 카메라, 보스 몸체, 파편, 높이 연출이 바닥 피격 근거를 가리지 않는다.
- 재시도 뒤 이전 플레이의 기억, 체력, 라운드가 남지 않는다.
- 탐색 베기나 일반 실행 실패로 죽었을 때 AI가 읽었다는 문구를 사용하지 않는다.

하나라도 다르면 수직 슬라이스는 FAIL이다.

## 10. 초행 플레이테스트

최소 다섯 명에게 규칙을 설명하지 않고 첫 전투를 맡긴다. 시작 화면에는 입력 세 개만 표시하고 AI 규칙과 정답은 말하지 않는다.

### 자유 첫 시도 합격선

다섯 명 중 네 명 이상이 다음 조건을 모두 만족해야 한다.

1. 첫 전투 입력 뒤 10초 안에 세 대시 기억, 미래 잔상, `LOCK`, `OUTSMART` 또는 `READ`를 경험한다.
2. 첫 결과 직후 보스가 어느 착지 측면을 왜 예측했는지 직전 세 대시로 설명한다.
3. `LOCK` 뒤 공격이 자신을 따라오지 않았다고 인식한다.
4. `OUTSMART`를 경험한 플레이어는 그 순간에는 체력이 줄지 않았고 직접 코어를 벤 횟수만큼만 줄었다고 설명한다.
5. 첫 결과가 `READ`인 플레이어는 결과 원인을 설명한 뒤, 첫 성공적인 반대 대시와 코어 공격을 경험한 시점에 직접 피해의 원인을 설명한다.
6. 이동·대시·공격 중 무엇으로 보스를 쓰러뜨리는지 구분한다.

### 사망·재도전 합격선

`READ` 사망 루트를 독립적으로 한 번 재현한다. 다섯 명 중 네 명 이상이 다음을 만족해야 한다.

1. 사망 뒤 3초 안에 `다시 속이기`를 누른다.
2. 새 플레이의 첫 `LOCK`에서 안내된 예측 반대 측면으로 실제 대시한다.
3. 열린 코어에 직접 공격을 넣어 방금 본 조언을 행동으로 증명한다.

### 즉시 전체 FAIL 조건

다섯 명 중 두 명 이상이 다음 중 하나를 말하면 전체 FAIL이다.

- “카메라를 돌려야 하는 줄 알았다.”
- “높이가 달라서 왜 맞았는지 모르겠다.”
- “보스가 잠근 뒤에도 나를 따라왔다.”
- “OUTSMART가 자동 피해인지 내 검격 피해인지 모르겠다.”
- “다음 판에 무엇을 바꿔야 할지 모르겠다.”

## 11. 실패했을 때의 디렉팅 원칙

- 직접 조작감이 약하면 첫 장갑 튕김, 코어 접촉, 타격 정지를 고친다.
- 무엇을 학습했는지 모르면 대시 흔적이 센서 조각으로 접히는 장면을 고친다.
- 예측 원인을 모르면 세 조각의 다수 결합과 미래 잔상의 연결을 고친다.
- `LOCK`이 불공정하면 정적, 금속음, 고정된 시선과 레일을 강화한다.
- 속임과 피해가 섞이면 `OUTSMART` 시 체력 표시를 정지시키고 검격 접촉 때만 감소시킨다.
- 코어 욕심의 위험이 안 보이면 세 번째 검격 직후 장갑 복귀 충격을 더 분명히 한다.
- 2.5D 높이 때문에 판정을 오해하면 연출 높이를 낮추고 바닥 그림자와 도형을 먼저 고친다.
- 재도전이 늦으면 기록을 줄이고 원인, 반대 측면, `다시 속이기` 순서를 앞당긴다.

상태 감사 여섯 번이 모두 일치하고 초행 플레이테스트가 합격하기 전에는 새 보스 패턴이나 학습 축을 추가하지 않는다.
