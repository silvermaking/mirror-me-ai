# Mirror Me AI — Kiln Reliquary 방향 잠금

## 한 문장

세 장의 도편에 구운 발놀림을 맹신한 소성 기계가 빈곳을 내려쳐 스스로 화구를 여는 2.5D 액션 보스전.

![Kiln Reliquary OUTSMART 기준 장면](./kiln-reliquary-outsmart-keyframe.png)

이 이미지는 런타임 자산이 아니라 카메라, 실루엣, 물질과 `OUTSMART` 동작의 기준이다. 이미지 속 임의 파츠 수와 세부 장식은 규칙이 아니다.

## 화면의 다섯 가지 진실

1. 실제 플레이어는 작은 실체와 짧은 청록 법랑 스키드로만 보인다.
2. AI가 기억한 세 번의 회피는 보스 등 위의 방향 절삭 도편 세 장으로 보인다.
3. 잠긴 예측은 움직이지 않는 산화철 바닥 표적과 팽팽한 기계 강선으로 보인다.
4. 파일드라이버가 빈 표적에 박히면 보스 몸 전체가 과회전하고 케이블이 흉부 셔터를 연다.
5. 열린 화구는 공격 기회일 뿐 자동 피해가 아니다. 플레이어 무기가 접촉할 때만 체력이 줄어든다.

## 카메라와 전투 평면

- 약 35도 고정 쿼터뷰이며 원형 전장 전체와 가장자리가 항상 보인다.
- 이동과 피격 판정은 하나의 2D 바닥 평면에만 존재한다.
- 카메라 회전, 수동 줌, 점프, 높이 판정과 수직 조준은 없다.
- 충격은 카메라 이동보다 포즈, 바닥 파임, 짧은 히트스톱과 반동으로 전달한다.

## 보스 실루엣과 물질

- 낮은 가마 몸통, 한쪽의 거대한 파일드라이버, 반대쪽의 작은 지지 집게로 비대칭을 만든다.
- 넓은 인간형 어깨, 대칭 양팔, 얼굴형 로봇 머리를 만들지 않는다.
- 그을린 주철, 갈라진 상아색 내화 도자, 어두운 황동, 오래된 내화벽돌을 사용한다.
- 청록은 실제 플레이어와 실제 종료 흔적에만 제한한다.
- 위험과 예측은 발광 자홍 홀로그램이 아니라 산화철 적색 표적과 기계 부품으로 표현한다.
- 열린 코어는 보석이나 에너지 구체가 아니라 셔터 뒤 실제 화구다.

## 7.5초 OUTSMART 리듬

- `0.0–0.9초`: 마지막 탐색 회피가 위험 밖에서 끝난다.
- `0.9–1.7초`: 세 번째 방향 도편이 선반에 꽂힌다.
- `1.7–2.6초`: 같은 쪽 도편이 래칫을 밀고 표적과 강선이 고정된다.
- `2.6–3.5초`: 플레이어만 반대로 회피하고 예측 표적은 움직이지 않는다.
- `3.5–4.6초`: 파일드라이버가 비어 있는 표적을 내려친다.
- `4.6–5.7초`: 보스가 과회전하며 흉부 셔터가 열린다.
- `5.7–7.5초`: 플레이어가 접근해 무기로 화구를 직접 타격한다.

## 금지 요소

- 청록·자홍 네온 SF, 홀로그램 인간, 발광 격자와 대칭 HUD 상자
- 다면체 로봇, 대칭 골렘, 고딕 장식, 룬과 해골
- 문 선택, 카드, 자동 전투와 자동 반사 피해
- 긴 마법 잔상, 과도한 파티클, 화면을 가리는 섬광
- 기준 이미지의 재질만 복제하고 보스의 예비동작·충돌·반동을 생략하는 것

## 첫 수직 슬라이스 PASS

- UI를 숨겨도 플레이어, 빈 예측 위치, 박힌 팔과 열린 화구가 구분된다.
- 무성 장면만 보고 `기억 → LOCK → 반대 회피 → 헛공격 → 코어 노출 → 직접 타격`을 설명할 수 있다.
- 320×180 축소 화면에서도 실제 플레이어와 산화철 예측 표적이 분리된다.
- 기존 이동·공격·대시·학습·피격 판정 테스트가 그대로 통과한다.
- 새 기능이나 새 공격을 추가하지 않고 기존 전투가 더 명확하고 무겁게 느껴진다.
