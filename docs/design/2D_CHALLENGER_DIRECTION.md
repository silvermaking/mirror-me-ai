# Mirror Me AI — 2D Challenger 방향 잠금

## 상태

- 공동 디렉터 승인: 2026-08-04
- 방향: **봉인 지도 판타지 《지도에 없는 왕국》**
- 기존 3D 런타임 보관: `codex/archive-3d-runtime` @ `630e0da`
- 이 문서는 새 2D 플레이어블의 시각·서사 계약이며 `src/game-core.mjs`의 판정을 바꾸지 않는다.
- 대화에서 승인한 생성 이미지는 구도 검토물일 뿐 게임 자산이 아니며 저장소에 커밋하지 않는다.

## 한 문장

**지도에서 이름을 잃은 기사가 자신의 세 회피 종점을 공식 지도로 봉인하려는 살아 있는 지도제작자를 속여, 지도 밖의 한 걸음으로 백지 코어를 여는 고정 쿼터뷰 2D 보스전.**

## 세계의 전제

세계는 발견되어 지도에 기록되는 것이 아니라, 지도에 기록되기 때문에 존재한다. 세계지도 수호자 **백지의 섭정 카르토그라프**는 예측할 수 없는 길을 재앙으로 판단해 지우고, 이름을 잃은 방랑 측량사 **레안**은 지도에서 삭제된 고향으로 이어지는 첫 길을 되찾으려 한다.

이 설정은 플레이 중 새 선택지나 명명 입력을 추가하지 않는다. 플레이어가 기존 규칙대로 예측 반대편에 도달한 순간, 그 결과를 **지도에 없던 장소가 생겼다**고 시각적으로 해석할 뿐이다.

## 판정과 세계 표현의 일대일 대응

| 변경하지 않는 게임 진실 | 화면에서 보이는 지도 판타지 표현 |
| --- | --- |
| 탐색 공격 종료 시 위험 구역 밖의 실제 좌·우 측면 하나만 표본으로 저장 | 보스에 연결된 매끈한 상아색 지도 명판 하나와 은제 측량침 하나가 켜진다. |
| 최근 유효 표본은 정확히 세 개 | 같은 크기의 지도 명판과 측량침 세 개가 보스 측면에 물리적으로 정렬된다. |
| 2/3 다수 측면으로 다음 착지 구역 예측 | 세 측량끈이 한쪽의 붉은 왕실 밀랍 인장으로 결속된다. |
| LOCK 순간 표적·시선·공격축·시점 고정 | 밀랍 인장과 대형 컴퍼스 도장 축이 굳으며 이후 플레이어를 추적하지 않는다. |
| LOCK 뒤 예측 반대편 위험 구역 밖에서 종료하면 OUTSMART | 실제 플레이어가 분절된 코발트 직선 흔적을 남기며 반대편의 미기록 위치에 선다. |
| 보스 공격이 고정 표적에 빗나감 | 대형 컴퍼스/왕실 도장이 빈 밀랍 인장 중심에 정확히 박힌다. |
| OUTSMART는 피해 없이 코어 노출만 발생 | 충돌 반동이 보스의 매끈한 지도 외피를 열어 순백색 백지 코어를 드러낸다. |
| 열린 코어의 직접 검격만 보스 HP 감소 | 레안의 부러진 경계선 검이 백지 코어에 닿을 때만 왕실 인장이 지워진다. |
| 패배 뒤 같은 판정 상태로 즉시 재도전 | 패배한 레안이 지도 삽화가 되고 은빛 서책나방이 기록을 먹어 다시 전장으로 떨어뜨린다. 판정과 이동 공간은 초기화된다. |

## 시각 문법

### 플레이어 — 레안

- 보스보다 작지만 320×180에서 전신과 검이 분리되는 크기
- 짙은 코발트 지도 망토, 밝고 비어 있는 얼굴, 비대칭 어깨선
- 한 손의 부러진 기사검은 공격 무기이자 지도 경계선을 끊는 표식
- 이동 흔적은 표적과 연결되지 않는 짧고 분절된 코발트 바닥 자국
- 공격은 상체와 하체가 분리되지 않은 전신 키포즈

### 보스 — 카르토그라프

- 화면 위쪽 중앙을 지배하는 비대칭 실루엣
- 검은 잉크 내부, 매끄러운 상아색 지도 직물/도자질 외피, 컴퍼스 왕관
- 오른쪽의 초대형 컴퍼스 도장과 왼쪽의 기억 명판 세 개로 기능을 분리
- OUTSMART 때 도장 접점에서 시작한 반동이 팔·몸통·외피 순서로 전달
- 얼굴 표정보다 측량 도구의 정렬과 붕괴로 확신과 오판을 표현

### 전장과 재질

- 고정 35도 정사영 쿼터뷰와 전체 원형 전장 유지
- 바닥은 찢기거나 구겨진 종이 더미가 아니라 **매끄러운 상아색 세계지도판**
- 지도 정체성은 얕은 등고선, 한 줄의 강, 금박 좌표, 컴퍼스, 측량침과 밀랍 인장으로 표현
- 보스 외피는 너덜한 종이 파편 대신 길고 유려한 큰 곡면으로 정리
- 종이 섬유·찢긴 가장자리·미세 지도 문자·미니어처 도시와 군대는 전투 화면에서 억제
- 플라스틱 PBR, 유광 3D 디오라마, 평면 UI 패널로 보이지 않는 무광 authored 2D 명암 사용

### 기능 색

- 플레이어와 실제 이동: 짙은 코발트
- 현재 위험: 옅은 산화 적색 원
- 고정 예측과 접점: 진한 주홍 밀랍 인장
- 기억: 상아 명판 + 은제 측량침 + 붉은 측량끈
- 보스 내부: 먹빛
- 열린 코어: 화면에서 가장 밝은 무결점 백색

## 첫 10초

1. 닫힌 지도 외피에 검이 튕겨 직접 공격만으로는 피해를 줄 수 없음을 보인다.
2. 세 번의 탐색 공격에서 같은 측면으로 피할 때마다 보스의 지도 명판에 측량침이 하나씩 박힌다.
3. 세 측량끈이 한쪽 밀랍 인장으로 모이고 컴퍼스 도장 축이 그 좌표에 고정된다.
4. 플레이어가 반대편으로 직선 대시해도 인장과 도장은 따라오지 않는다.
5. 도장이 빈 인장을 내려찍고 보스 외피가 반동으로 열리며 백지 코어가 나타난다.
6. 플레이어가 접근해 코어를 직접 벨 때만 HP가 줄고, 두 번 또는 세 번 공격한 뒤 이탈한다.

## 즉시 재도전

- 게임 오버는 별도 화면으로 전환하지 않고 같은 지도판 위에서 발생한다.
- 레안이 납작한 지도 삽화가 되고, 마지막 세 기억과 고정 인장이 원인으로 남는다.
- 은빛 서책나방이 패배 기록 한 줄을 먹으면 레안이 같은 전장으로 떨어져 즉시 재시작한다.
- 이전 패배의 찢김과 먹힌 흔적은 짧은 시각 잔상만 허용한다. 새 길, 능력, 지형, 유리한 판정은 만들지 않는다.

## 즉시 FAIL

- 전체 이동 경로·속도·정지·공격·대시 시점을 AI가 추가 학습
- 검을 꽂기, 장소 이름 선택, 보호·대기 같은 새 상호작용
- 모든 길을 LOCK 좌표로 강제하거나 반대편 이동을 막는 성벽·군대·지형
- 지도 산·강·도시의 높이 또는 충돌이 실제 판정을 변경
- 헛공격만으로 자동 피해 발생
- LOCK 이후 밀랍 인장·보스 시선·도장 축이 플레이어를 다시 추적
- 종이 섬유와 찢긴 파편이 화면을 지배하거나 플레이어보다 먼저 보이는 미세 장식
- 생성 시안을 그대로 잘라 스프라이트나 게임 배경으로 사용

## 제작과 역할

- Session 1은 기획, 작업 지시, 독립 검수와 최종 채택만 담당한다.
- 콘셉트 이미지, 스프라이트, 모션 키포즈는 디자인 subagent 또는 별도 디자인 세션이 제작한다.
- Session 2는 방향 잠금 SHA 이후 별도 `codex/2d-challenger` worktree에서 플레이어블을 구현한다.
- 실제 자산은 재현 가능한 원본·스프라이트 시트·로컬 정적 파일로 만들고 생성 검토 이미지를 런타임 자산으로 사용하지 않는다.
- 기존 `src/game-core.mjs`와 `tests/game-core.test.mjs`는 수정하지 않는다.
- 기존 3D GLB와 Three.js 런타임은 `codex/archive-3d-runtime`에 보존하며 2D 구현을 위해 삭제하거나 덮어쓰지 않는다.

## PASS

- 320×180 무문구 화면에서 player / boss / memory 3개 / danger / fixed target / driver / blank core가 모두 구분된다.
- 분절형 코발트 흔적은 표적과 분리된 직선 회피로 읽히며 원형 이동이나 공격 빔으로 보이지 않는다.
- 대형 도장 중심은 플레이어가 아니라 고정 밀랍 인장의 2D 바닥점에 닿는다.
- `기억 → LOCK → 반대 회피 → 헛타격 → 백지 코어 → 직접 검격`이 무성 8초 영상에서 설명 없이 읽힌다.
- 명명·강제 경로·지형 충돌·소환수·자동 피해 없이 기존 판정 테스트가 모두 통과한다.
